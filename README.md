# 練習用の文字起こし（架空）

**ここに入っているのは、すべて架空のプロジェクトの、架空の会議です。**
実在の人物・部署・取引先・数字とは関係ありません。

自分の会議の録音を用意しなくても、このワークスペースを一通り試せるようにするための素材です。

## 何のプロジェクトか

医師向けの **Web講演会シリーズを、外部イベント会社への委託から内製に切り替える**、という架空の
社内プロジェクトです。通称「ミナト」。全5回の定例会が入っています。

| ファイル | 何を扱った回か |
| --- | --- |
| `01_2026-04-13_文字起こし.txt` | 現状把握と、内製化する範囲を決める |
| `02_2026-04-27_文字起こし.txt` | 費用の内訳と、使うツールを決める |
| `03_2026-05-18_文字起こし.txt` | パイロット直前に出た詰まりを片づける |
| `04_2026-06-08_文字起こし.txt` | パイロットの振り返りと、誰が承認するか |
| `05_2026-06-29_文字起こし.txt` | 下半期を何回内製にするかを決める |

**回をまたいで話が続きます。** 前回の ToDo が終わっていたり、終わっていなかったり、
前回決まらなかったことが今回決まったりします。だから5回まわすと、
「複数の会議を横断して読む」ことに意味が出ます。

## 使い方

**1回ぶんずつ、順番にやってください。**

```
1. 01_2026-04-13_文字起こし.txt の中身を全部コピーして、チャット欄に貼る
2. 「議事録にして」と添える
3. 用語を聞かれるので答える
4. 保存された議事録を開いて、確認を求められた箇所を直す
```

これを 01 から 05 まで繰り返します。

**3回目が終わったところで、一度こう頼んでみてください。**

```
次回のアジェンダを作って
```

前回の ToDo が仕分けられて、確認を求められます。**そこで「上げる／落とす」を直すのが本番です。**
出てきたアジェンダと、そのあと `04_2026-06-08_文字起こし.txt` で実際に話されたことを見比べると、
準備で何が効いたかが分かります。

5回目が終わったら、こう頼んでみてください。

```
meetings/ の議事録を全部読んで、未完了のToDoを担当者別に一覧にして
```

```
4月から6月で、決まったことと、まだ決まっていないことを分けて出して
```

**4月に出た論点のいくつかは、6月になってもまだ決まっていません。**
そういうものが自分で見つけられるか、が5回まわす意味です。

## 途中で「この用語は正しいですか」と聞かれます

**音声認識は人名をよく間違えます。** この文字起こしにも、実際の音声認識が出すのと
同じ種類の誤変換が入っています。

答えると `user-dictionary.md` に溜まります。**溜まるほど、次の回で聞かれる数が減ります。**
1回目で5件聞かれたものが、3回目には1件になる。それが辞書の効き方です。

答えが分からない用語は「わかりません」で構いません。そのまま進みます。

> **話者の名前（`[10:02:14] Yuka Morikawa:` の部分）は正しく出ます。**
> 会議の参加者名簿から取っているためです。間違うのは、**会議に出ていない人の名前**
> ——取引先の担当者、他部署の窓口、承認者——のほうです。実際もそうなります。

## 終わったら

この `_練習用/` フォルダは消して構いません。架空のデータなので、残しておく意味は
練習をやり直したいときだけです。
